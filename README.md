# SSI Production app

Phone app for S S International production tracking. Install: open https://shadabahmed1001.github.io/ssi-app/ in Chrome, menu → Add to Home screen.

This repository holds only the program. Business data (lots, recipes, costs) is never stored here: it is loaded on the phone from the Excel workbook and database, and kept on the phone.

Built from the Claude version by `sa/build.sh`; updated by Claude.
